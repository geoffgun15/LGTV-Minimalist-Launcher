# C4 Home
<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
User accepted recommended static HTML, CSS and JavaScript packaged as a webOS app.

## Users
The owner of a rooted LG C4 OLED, using a remote from a sofa.

## Product Purpose
Open installed TV apps and HDMI inputs quickly from a personal launcher.

## Operating Context
webOS TV 10.3.1; webOS Dev Manager is installed on the computer. User requested a separate app first: preserve the existing Home button and boot behavior.

## Capabilities and Constraints
Installed-app inventory, named HDMI inputs, local favorites, D-pad and Magic Remote support, OLED idle fade. No accounts or network content required by the launcher.

## Brand Commitments
User chose dark and minimal.
